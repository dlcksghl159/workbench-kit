# 확인 문제 카드 (외워서 들어가기)

진행 순서: "제출물 확정하고 문제풀기" → 문제 생성 대기 5~10분 → "문제 풀기" → 문항당 5분.
AI, 외부 창, 복사·붙여넣기, 이전 문항으로 돌아가기 모두 불가. 직접 타이핑해요.

## 4문장 공식
1. **결론**: "저는 ~하도록 구현했습니다."
2. **근거**: "[파일/함수]에서 ~하고, [테스트/검증]으로 확인했습니다."
3. **한계**: "다만 ~한 입력이나 상황에서는 ~할 수 있습니다."
4. **다음**: "그래서 ~를 추가로 검증하거나 ~로 개선하겠습니다."

## 질문 전제가 실제 구현과 다를 때 첫 문장
"질문의 전제와 실제 구현이 다릅니다. 실제로는 ~하도록 구현했습니다." 그다음 4문장 공식대로 써요.

## 자주 나오는 질문 유형
- 왜 이 구조나 방법을 골랐나 (버린 대안과 이유)
- 이런 입력이나 장애가 오면 어떻게 되나
- 가장 약한 부분과 그 영향
- 결과가 맞다는 걸 어떻게 확인했나
- AI가 만든 결과를 어떻게 검증하고 고쳤나
- 보안·데이터 위험
- 시간이 더 있으면 무엇을 하겠나

## 5분 쓰는 법
- 30초 생각, 3분 쓰기, 1분 다듬기.
- 파일명이나 함수명을 하나는 꼭 넣어요. 구체적일수록 좋아요.
- 모르면 추측하지 말고 "확인하지 못했다, 이렇게 확인하겠다"로 써요.
